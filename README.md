## Türkçe

ÇİZEN Viewer Max, STEP, CATIA, SOLIDWORKS, NX, Creo ve diğer CAD dosyalarını iOS ve Android
cihazlarda açmaya, ölçmeye, kesit almaya, analiz etmeye ve 2D resim çıkarmaya yarayan bir mobil
uygulamadır. Bu repo, uygulamanın tanıtım sitesini ve yasal sayfalarını içerir. Uygulamanın kaynak
kodu bu repoda değildir.

## English

ÇİZEN Viewer Max is a mobile app for iOS and Android that opens STEP, CATIA, SOLIDWORKS, NX, Creo
and other CAD files, with tools for measuring, sectioning, analysis and 2D drawings. This repository
contains the app's marketing site and legal pages in Turkish and English. The app's source code is
not part of this repository.
